# Evidence

Persist reproducible gate evidence here.

Suggested layout:

`docs/evidence/GATE-N/YYYY-MM-DD_<short-description>/`

Each evidence set should identify:

- branch
- commit
- commands
- toolchain
- device(s)
- OS/Android version
- sanitized logs/results
- conclusion
- PASS/FAIL/BLOCKED/NOT_TESTED status

Never include secrets, tokens, Wi-Fi passwords, GPS traces, media content or unnecessary PII.
